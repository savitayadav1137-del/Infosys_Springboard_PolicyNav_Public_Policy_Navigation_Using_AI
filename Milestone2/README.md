🔐 PolicyNav – Milestone 2
Secure Authentication System with OTP & JWT
📌 Project Overview
This project is part of the Infosys Virtual Internship. Milestone 2 focuses on enhancing the authentication system by implementing:

✅ Secure password hashing using bcrypt

✅ JWT-based authentication

✅ OTP verification

✅ Input validation improvements

✅ Enhanced security checks

✅ Deployment using ngrok

The system is built using Streamlit, SQLite, and Python security libraries.

🚀 Features Implemented in Milestone 2
🔑 Authentication Features

User Signup

User Login

Forgot Password

Security Question Verification

OTP-based authentication

JWT Token generation for secure sessions

🛡 Security Enhancements

Password hashing using bcrypt

JWT token-based session management

Input validation (No spaces allowed in password/security answers)

Secure database storage using SQLite

Token expiration handling
